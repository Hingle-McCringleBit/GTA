# GTA-Style Open World Game

A comprehensive 3D open-world game built with Unity featuring advanced driving mechanics, police AI systems, realistic shooting, and emergency response dispatch.

## Features

- **Advanced Driving Mechanics**: Realistic vehicle physics, suspension, traction control
- **Dynamic Police System**: NYPD-style police and SWAT response
- **Advanced Shooting Mechanics**: First-person shooting with ballistics
- **Emergency Response**: Ambulances deploy on deaths, firetrucks on fires
- **AI Traffic System**: Realistic NPC driving patterns
- **City Infrastructure**: Buildings, roads, street lighting
- **Sound & Visuals**: Audio effects, particle systems, environmental effects
- **Wanted System**: Dynamic threat level based on player actions

## Installation

1. Open this project in **Unity 2022.3 LTS** or higher
2. Load the main scene: `Assets/Scenes/MainGame.unity`
3. Play and enjoy!

## Controls

- **WASD**: Move / Drive
- **Space**: Jump / Handbrake
- **Left Click**: Shoot
- **E**: Enter/Exit Vehicle
- **Tab**: Wanted Level Display
